## 已确认的项目事实

- 原项目同时存在固定编排的 RAG 问答和 ReAct Agent 两条入口；两者共享知识检索能力，但决策者不同。
- 文档直接分块的有效主链是：识别 MIME → 解析结构块 → 分块 → Embedding → 同步写关系数据与向量索引。
- 原项目文档状态为 `pending → running → success/failed`；通用摄取任务状态使用 `pending → running → completed/failed`，两个词汇体系不能混用。
- RAG 问答的检索结果不是最终答案。片段会被格式化成上下文，再与问题和提示词一起交给聊天模型生成回答。
- 来源 `SourceRef`、模型实际使用的检索上下文和最终落库消息存在关联，但用途不同；后续讲到引用时需要明确区分。
- 原项目当前“知识文档 → 自定义 Pipeline”入口处于重构暂停状态，直接分块内核才是稳定 Happy Path；教学不能把暂停能力误写成已工作的主流程。

- 学生已完成环境验证，并能提交第一次红灯的关键编译错误。

- 学生发现高度重合的测试逐条生成会让反馈循环过碎。后续将同一执行路径、由同一次实现共同满足的用例组成测试矩阵一次生成；独立需求仍分别停在可验证节点。
