# ragent-st

这是 Ragent 的渐进式教学重建项目，不是原项目的精简副本。

第 1 课已经完成：已知退货问题和未知问题兜底均已有最小实现与测试，并由学生亲自运行通过。项目目前只包含 Java 17、Maven 和 JUnit 5 所需的最小构建配置；Spring Boot、数据库、向量库、模型 SDK 等都要等真实需求出现后再引入。

课程资料位于相邻目录 `../tutorial/`，长期约束见 `../tutorial/工作守则.md`。

## 当前验证命令

```bash
mvn test
```

当前应有两个测试全部通过：已知退货问题返回政策，未知发票问题返回诚实兜底。
