# ragent-st

这是 Ragent 的渐进式教学重建项目，不是原项目的精简副本。

第 1～3 课已经完成。当前系统能读取约定格式的 UTF-8 文本/Markdown 文件，按空行生成内存知识，再使用关键词相关性选择答案和来源。项目仍只使用 Java 17、Maven 和 JUnit 5；Spring Boot、数据库、向量库、模型 SDK 等都要等真实需求出现后再引入。

课程资料位于相邻目录 `../tutorial/`，长期约束见 `../tutorial/工作守则.md`。

## 当前验证命令

```bash
mvn test
```

当前应有六个测试全部通过：四个已有检索测试，以及正常知识文件和空文件两个加载测试。
