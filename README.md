# ragent-st

这是 Ragent 的渐进式教学重建项目，不是原项目的精简副本。

第 1 课已经完成并提交。第 2 课已经加入多条内存知识、关键词相关性选择、回答来源及对应测试，正等待学生统一运行验收。项目仍只使用 Java 17、Maven 和 JUnit 5；Spring Boot、数据库、向量库、模型 SDK 等都要等真实需求出现后再引入。

课程资料位于相邻目录 `../tutorial/`，长期约束见 `../tutorial/工作守则.md`。

## 当前验证命令

```bash
mvn test
```

当前应有四个测试全部通过，分别覆盖退货回归、第二条知识、相关性选择和未知问题边界。
