# ragent-st

这是 Ragent 的渐进式教学重建项目，不是原项目的精简副本。

第 1～4 课已经完成。第 5 课已用阿里云百炼的 OpenAI 兼容接口接通文本向量化、Top-1 检索和受证据约束的回答生成，并由学生完成真实网络验收。自动测试继续使用本机 HTTP 桩；`BailianRagLiveIT` 用于手动复验真实网络。

课程资料位于相邻目录 `../tutorial/`，长期约束见 `../tutorial/工作守则.md`。

## 当前验证命令

```bash
mvn test
```

当前应有十一个测试全部通过：九个已有问答、文件与向量检索测试，以及两个模型 HTTP/RAG 流程测试。
